## Project Description
A menu driven Python calculator built using Git and Github feature-branch workflow. Each arithmetic operation (addition, subtraction, multiplication, division) was developed on its own branch, committed at least twice,and merged into 'main' through a Pull request. The final version integrates all four operations into a single application.

## Branch Structure
- 'main' - calculator skeletion and final integrated version
- 'addition_Silerio' - addition operation
- 'subtraction_Silerio' - subtraction operation
- 'multiplcation_Silerio - multiplication operation
- 'division_Silerio' - division operation, including divide by zero handling

## Program Features
- Menu driven interface (Addition, Subtraction, Multiplication, Division, Exit)
- Continuous execution until the user chooses to exit
- Input validation for non-numeric entries
- Division by zero handling
- Clear function separation for each operation
